# Jack Code Debugging Report Template

This is a bundled core template/reference file. Jack Code Debugging does **not** overwrite this file at runtime.

Each debugging invocation creates a new durable report under `Debugging/Reports/` using a date/time-based unique filename, for example:

`Debugging_Report_2026-09-09_14-41-02_123456_a1b2c3d4.md`

That run-specific file receives only the frozen **user-origin** pre-pass diagnostic intake as Pass 0, followed by Passes 1 through 5 and the Final Debugging Report. Pre-stage native reasoning and assistant intake dialogue are ephemeral and are not promoted into the durable report.

For live Passes 1–5, Jack re-projects the exact user-origin Pass 0 intake into every fresh pass. Passes 2–5 additionally receive only a compact host-derived confirmed prior-finding registry from already committed outcomes. Full handoffs, repair guidance, preservation constraints, verification plans, residual observations, future-candidate suggestions, and native reasoning/tool protocol remain out of later live passes while this durable report retains the complete handoffs for the final reporter.
