PI BRIDGE REGRESSION INVARIANTS
-------------------------------
The Node lifecycle harness must continue to prove:

1. The private run marker is accepted only as extension-injected Pi input.
2. The marker is stripped before model-visible processing.
3. taskId/runId/runEpoch bind from positive run evidence.
4. user/assistant message events inside the run carry the same bound identity.
5. an event after agent_end does not inherit the controlled task/run.
6. automatic retry keeps runId and advances runEpoch.
7. running cancellation becomes terminal immediately but cannot overlap a new
   controlled task before physical settlement.
8. completed terminal SSE task snapshot has settledAt and runOpen=false.
9. cancelled terminal SSE task snapshot retains the same run ID, has settledAt,
   and has runOpen=false.
10. a queued cancellation is swallowed at its exact private marker and does not
    start a controlled model run.

JACK GATEWAY REGRESSION INVARIANTS
----------------------------------
The Python orchestration tests must continue to prove:

- task/run/epoch/attribution fields are promoted from Pi wrappers rather than
  inferred from timing;
- raw source_event is preserved;
- untagged events remain untagged;
- sequence numbers strictly increase;
- bounded replay returns retained events in order;
- a request older than the retained window returns HTTP 409
  orchestration_replay_gap.

LIVE RELEASE INVARIANTS
-----------------------
When re-validating a release on Windows, preserve these already accepted checks:

A. Concurrency
   - Configure Jack through the launcher Advanced menu.
   - Set Maximum concurrent Kernel requests = 2 and save.
   - Prove physical backend overlap in LM Studio logs; application-level "running"
     status alone is not sufficient evidence of simultaneous inference.

B. Replay
   - connect raw SSE
   - record seq N and disconnect
   - generate controlled events
   - reconnect with ?after=N or Last-Event-ID
   - require strict order, no duplicates, and preserved source/source_event
   - stale positions older than the retained 512-event window must receive 409

C. Cancellation
   - cancel a physically running controlled task
   - allow logical cancelled + runOpen=true during abort propagation
   - reject new controlled work while still unsettled
   - after agent_settled require same task/run + settledAt + runOpen=false

D. Primary Pi unavailable
   With Jack still alive and :8013 actually unavailable, all four Pi-dependent
   public Jack operations must fail deterministically:

     GET  /jack/orchestration/status       -> 502
     POST /jack/orchestration/tasks        -> 502
     POST /jack/orchestration/tasks/cancel -> 502
     POST /jack/orchestration/session/new  -> 502

   Accepted body:

     {"detail":"Pi control bridge is unavailable"}

   Do not add a direct-Pi or direct-backend control fallback.
